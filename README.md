A faster drop-in for make.fun's own csv-reader 1.0.0: it reads broken CSV files
exactly as csv-reader does — same columns, rows and errors on every case —
but scans with `indexOf`/`slice` instead of one character at a time, so it
runs several times faster on large inputs.

## Run it

```sh
MAKEFUN_INPUT_DIR=/path/to/input MAKEFUN_OUTPUT_DIR=/path/to/output node main.ts
```

`main.ts` reads every case from `$MAKEFUN_INPUT_DIR/cases.json` and writes
the answers to `$MAKEFUN_OUTPUT_DIR/answers.json`. Node 22, standard library
only, no dependencies.
